# Amethyst

Auto-fishing macro for Fisch (Roblox), made by imsaintt.

## Install

1. Download **Amethyst.zip** from this page (click it, then the download button).
2. Unzip it into its own folder, e.g. `Documents\Amethyst`.
3. Run **Amethyst.exe**. If keys do not reach the game, run it as administrator.

## Updates

Amethyst tells you when a new version is out ("Update available" in the left panel).
Open **About** and press **Update** - your settings and profiles are kept.
