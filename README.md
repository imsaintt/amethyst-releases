# Amethyst

Auto-fishing macro for Fisch (Roblox), made by imsaintt.

## ⬇️ [Download Amethyst (latest version)](https://github.com/imsaintt/amethyst-releases/raw/main/Amethyst.zip)

Click the link above - it downloads **Amethyst.zip** straight away (no need for the green "Code" button).

## Install

1. Download **Amethyst.zip** with the link above.
2. Right-click it, **Extract All...**, and pick a folder of its own, e.g. `Documents\Amethyst`.
3. Open that folder and run **Amethyst.exe** (keep the `gui` folder next to it).
   - Windows says "Windows protected your PC"? Click **More info**, then **Run anyway**.
   - Keys don't reach the game? Run it as administrator.

Don't run Amethyst.exe from inside the zip without extracting it - your settings would get lost.

## Updates

Amethyst tells you when a new version is out ("Update available" in the left panel).
Open **About** and press **Update** - your settings and profiles are kept. No need to download again.

## Discord bot (optional)

Check on the macro or stop it from your phone: in Amethyst open **Utilities → Discord Bot**, click
**Add bot**, type `/link` in Discord, paste the code and press **Link**. Then use `/status`,
`/screenshot` and `/stop` anywhere in Discord.
